# Detection PS-001 — PowerShell Script Block Activity

## Objective

Collect PowerShell script-block telemetry so analysts can review suspicious or
encoded commands and map activity to MITRE ATT&CK T1059.001.

## Configuration

- Enabled PowerShell script-block logging
- Enabled PowerShell module logging
- Added `Microsoft-Windows-PowerShell/Operational` to the Wazuh agent collection
- Installed custom rule `100101` from `Rules/ps001_lab_rules.xml`
- Preserved the original Wazuh agent configuration as a local backup

## Validation

A harmless command containing the marker `SOC-LAB-PS-001` generated Windows
Event ID 4104. On 2026-10-29, Wazuh `wazuh-logtest` 4.14.7 decoded a sanitized
4104 sample containing the end-to-end marker, matched rule `100101`, assigned
level 5, mapped T1059.001, and reported **Alert to be generated**. This verifies
the manager-side rule logic. Live endpoint-to-indexer Rule 100101 evidence is
outside the defined validation scope and is not claimed.

## Analyst Guidance

Review the full script block, user context, parent process, encoded content,
downloads, credential access, security-tool changes, and related network events.
