# Detection FIM-001 — Windows Startup Folder Monitoring

## Objective

Detect files that are created, modified, or deleted in the shared Windows
Startup directory.

## Data Source

Wazuh File Integrity Monitoring (`syscheck`) on `WIN-ENDPOINT-01`.

## Relevant Rules

- `554` — File added to the system
- `550` — Integrity checksum changed
- `553` — File deleted

## Monitored Path

`C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup`

## Validation

Revalidated on 2026-09-17 by creating, modifying, and deleting the harmless file
`wazuh-fim-lab-test.txt`. Wazuh produced all three expected alerts in real time.

## Analyst Guidance

Review the filename, hashes, owner, timestamps, and whether the change was
authorized. Unexpected executable or script files in a Startup location should
be escalated because they can indicate persistence.
